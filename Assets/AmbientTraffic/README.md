# Ambient Traffic Jam

Cosmetic stop-and-go background traffic for Unity (URP). Cars pack
bumper-to-bumper in lanes, follow the car ahead, and ripple through
go/stop waves while a camera-anchored window recycles them to keep the
belt full. No colliders during normal play, deterministic (private RNG).

**Requirements:** Unity 6000.3+ and the Universal Render Pipeline.

## Quick start
1. Add the `AmbientTraffic` component to an empty GameObject.
2. Add one or more lanes; assign your car prefabs to each lane.
3. Press Play. See `Documentation/Documentation.pdf` for full details and the
   `Demo/AmbientTrafficDemo` scene for a working setup.
